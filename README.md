# vcmc-enderchest

エンダーチェストの容量を増やせる Folia 26.3 向けプラグインです。今入っている中身はそのまま使え、コマンドで容量を拡張できます。

## 動作環境

| 項目 | バージョン |
|---|---|
| サーバー | Folia 26.3（`folia-api 26.3.build.6-alpha` でビルド） |
| Java | 25 以上 |

## 機能

- **大きなエンダーチェスト**: 既定の容量は 41 枠です。標準の 27 枠の 1.5 倍は 40.5 枠なので、切り上げています。設置したエンダーチェストを右クリックしても、`/enderchest` から開いても、中身は同じです。
- **今の中身はそのまま**: 最初の 27 枠は標準のエンダーチェストそのものです。導入前に入れていた物は、そのまま最初の 27 枠に表示されます。
- **容量の拡張**: `/enderchest expand <プレイヤー> <枠数>` で増やせます。投票ショップなどから、コンソールで実行する使い方を想定しています。
- **消えない作り**: 容量を減らしても、容量を超えた枠の中身は保管したままにします。容量を戻すと表示されます。
- **ページ**: 54 枠までは 1 画面、それより多いと 45 枠ずつのページに分けて、最後の行の矢印で切り替えます。使えない枠は灰色のガラス板で表示します。

## コマンド

`/ec` は `/enderchest` の別名です。

| コマンド | 内容 | 権限 | 既定 |
|---|---|---|---|
| `/enderchest` | 自分のエンダーチェストを開く | `vcmcenderchest.command.open` | 全員 |
| `/enderchest info` | 自分の容量を見る | `vcmcenderchest.command.open` | 全員 |
| `/enderchest info <プレイヤー>` | ほかのプレイヤーの容量を見る | `vcmcenderchest.admin.info` | OP |
| `/enderchest expand <プレイヤー> <枠数>` | 容量を増やす | `vcmcenderchest.admin.expand` | OP |
| `/enderchest set <プレイヤー> <枠数>` | 容量を決める（27〜上限） | `vcmcenderchest.admin.set` | OP |
| `/enderchest reload` | `config.yml` と `lang` フォルダを再読み込み | `vcmcenderchest.admin.reload` | OP |

`vcmcenderchest.admin` を付けると、管理用の権限をまとめて付けられます。プレイヤーはオンラインでなくてもかまいません（一度サーバーに来たことのある名前に限ります）。

`/enderchest` はどこからでも開けます。設置したエンダーチェストでだけ使わせたいときは、`vcmcenderchest.command.open` を外してください。vcmc-menu のボタンも使えなくなります。

### 投票ショップからの拡張

投票ショップの商品に、コンソールで実行するコマンドとして設定します。1 行（9 枠）増やす例です。

```
enderchest expand %player% 9
```

`%player%` はショップのプラグインに合わせて書き換えてください。

- 拡張したプレイヤーには、増えた枠数がプレイヤーの言語で伝わります。次にエンダーチェストを開いたときから使えます。
- すでに上限のときは拡張せず、プレイヤーに「運営へお知らせください」と伝え、コンソールに警告を出します。投票ショップのポイントは使われているので、必要なら返してください。
- 上限まで残りが少ないときは、上限まで増やして、増えた枠数を伝えます。

## 設定（config.yml）

```yaml
# 既定の容量（枠数）。標準の 1.5 倍は 40.5 枠なので、切り上げて 41 枠にしています
default-slots: 41
# 容量の上限。/enderchest expand ではこれより増えません
max-slots: 135
```

容量は「既定の容量 + プレイヤーごとの追加分」で決まります。`default-slots` を変えても、拡張した分はそのまま足されます。容量は 27 枠より少なくも、上限より多くもなりません。

## データの保存場所

| データ | 場所 |
|---|---|
| 最初の 27 枠 | 標準のエンダーチェスト（プレイヤーデータ） |
| 28 枠目以降 | プレイヤーデータの PersistentDataContainer（`vcmc-enderchest:extra`） |
| 容量（追加分） | `plugins/vcmc-enderchest/capacity.yml` |

- 中身はすべてプレイヤーデータに入るので、持ち物と同時に保存されます。
- 開いている間は操作のたびに保存し、閉じたとき、ログアウトしたとき、サーバーを止めたときにも保存します。
- 保存に失敗したときは、中身を `plugins/vcmc-enderchest/recovery/` へ書き出します。
- `capacity.yml` は、サーバーの起動中に手で編集しないでください。読み込めないときは容量をすべて既定にし、ファイルは書き換えません。
- プラグインを外しても、最初の 27 枠は普通のエンダーチェストとして使えます。28 枠目以降の中身はプレイヤーデータに残り、入れ直せば戻ります。

## 注意

- エンダーチェストはサーバーごとです（標準のエンダーチェストと同じ）。容量の拡張もサーバーごとなので、拡張コマンドは使うサーバーで実行してください。
- vcmc-openinv の `/openender` で見えるのは、最初の 27 枠だけです。本人がエンダーチェストを開いている間は、`/openender` で編集しないでください。あとから閉じた方の内容で上書きされます。
- `/ec` は EssentialsX などのほかのプラグインと重なることがあります。そのときは `/enderchest` を使ってください。

## 多言語対応

プレイヤーのクライアントの言語設定に合わせて、メッセージを自動で切り替えます。ゲーム中に言語を変更すると、次のメッセージから反映されます。

| クライアントの言語 | 表示する言語 | 文面の場所 |
|---|---|---|
| 日本語 | 日本語 | `config.yml` の `messages` |
| English（各地域） | English | `lang/en.yml` |
| 简体中文 | 简体中文 | `lang/zh_cn.yml` |
| 繁體中文（台灣）、文言 | 繁體中文（台灣） | `lang/zh_tw.yml` |
| 繁體中文（香港） | 繁體中文（香港） | `lang/zh_hk.yml` |
| 上記以外 | English | `lang/en.yml` |

コンソールへのメッセージとログは日本語のままです。

`lang` フォルダのファイルは初回起動時に作られます。編集して `/enderchest reload` を実行すると反映されます。ファイルに無いキーは jar 内の既定の文面を使います。

## テスト手順

### 自動テスト

```
mvn package
```

容量の計算、画面の配置（ページ分けと使えない枠）、容量を減らしたときに中身を消さないこと、`capacity.yml` の保存と読み込み、設定値の確認、翻訳ファイルを確認します。

### ゲーム内で確認してほしい項目

- [ ] 導入前に標準のエンダーチェストへ入れていた物が、最初の 27 枠に表示される
- [ ] 設置したエンダーチェストを右クリックすると 41 枠の画面が開き、蓋が開閉して音が鳴る
- [ ] スニークしながらブロックを持って右クリックすると、エンダーチェストの上にブロックを置ける
- [ ] 28 枠目以降に入れた物が、閉じて開き直しても、ログアウトしても、サーバーを再起動しても残る
- [ ] 灰色のガラス板（使えない枠）とページの矢印は、クリック、Shift クリック、数字キー、ドラッグで取り出せない
- [ ] `/enderchest expand <自分> 20` で 54 枠を超えるとページに分かれ、矢印で切り替えても中身が消えも増えもしない
- [ ] `/enderchest set <自分> 30` で減らすと「保管されています」と表示され、戻すと元の場所に表示される
- [ ] 開いている間にサーバーを止めても、中身が残る

## コード構成

- `VcmcEnderChestPlugin.kt`: メインクラス。初期化と停止時の保存。
- `gui/EnderChestGui.kt`: 画面を開き、ページを切り替え、中身を保存します。
- `gui/Controls.kt`: 使えない枠やページの矢印など、画面に置くだけのアイテム。
- `listener/EnderChestBlockListener.kt`: 設置したエンダーチェストを右クリックしたときに、この画面を開きます。
- `command/EnderChestCommand.kt`: `/enderchest`。
- `storage/EnderChestData.kt`: 標準のエンダーチェストとプレイヤーデータへの読み書き。
- `storage/Recovery.kt`: 保存できなかった中身の書き出し。
- `CapacityStore.kt`: `capacity.yml` の読み書き。
- `logic/`: 容量の計算、画面の配置、開いている間の中身。サーバーが無くてもテストできます。
- `Messages.kt`, `i18n/`: 受け取る人の言語で文面を作ります。

## ビルド

Java 25 が必要です。

```
mvn package
```

`target/vcmc-enderchest-<バージョン>.jar` が生成されます。
